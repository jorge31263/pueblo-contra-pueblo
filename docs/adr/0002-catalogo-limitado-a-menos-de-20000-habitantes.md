# El catálogo solo incluye municipios de menos de 20.000 habitantes

España tiene unos 8.100 municipios. Si entran todos, las rondas contra una
capital se resuelven sin pensar y el juego deja de ser sobre pueblos. El corte
en 20.000 habitantes conserva cerca del 96% de los municipios y mantiene el
tema.

El umbral se fija sobre el padrón del momento en que se genera el snapshot de
datos, así que un municipio puede entrar o salir del catálogo de un año para
otro.
